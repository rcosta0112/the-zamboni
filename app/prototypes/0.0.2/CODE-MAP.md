Per frame, in order (`main.ts`): input → sound (volumes, the ship's noise) → a cutscene (or skip) → fixed steps (ladders or character, then doors and ramp) → door and ramp sounds, the boombox, the jetpack rack, her outfit with Ink and her locker's clothes, the ladder's sound → her animation, footsteps → camera → the jetpack's glow → see-through rules → see-through shader values → interaction → world, the scenery, crew, lights → render.
