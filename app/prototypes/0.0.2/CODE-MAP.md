Outside `src/`: `index.html`; `src/style.css` has the prompt, help and pause overlays. The button, the progress bar and the tokens (colours, fonts) are in [`app/packages/ui`](../../packages/ui/README.md); the screen's images and fonts in `app/prototypes/0.0.2/public/ui/`. Scripts run outside the browser (exports, the scripted check `npm run smoke`, the one-question `npm run probe`, the records of changes to the ship file) are listed in [`app/prototypes/0.0.2/tools/README.md`](tools/README.md).

Until the start button is used, nothing is simulated: the frame stops after the sound while loading, then is made in full under the start screen. Per frame, in order (`main.ts`): input → sound (volumes, the ship's noise) → a cutscene (or skip) → fixed steps (ladders or character, then doors and ramp) → door and ramp sounds, the boombox, the jetpack rack, her outfit with Ink and her locker's clothes, the ladder's sound → her animation, footsteps → camera → the jetpack's glow → see-through rules → see-through shader values → interaction → world, the scenery, crew, lights → render.
