## Known traps

- **gltf-transform's `prune` in an export step:** limit it (`propertyTypes`, `keepAttributes: true`): by default it drops the lights' nodes and the normals of unlit meshes (the see-through copies read them).
- **Before any export:** read *Before the next export* in [`asset-pipeline.md`](../architecture/asset-pipeline.md#before-the-next-export). **Exporting:** `npm run export:ship` / `export:crew` / `export:player` (in `app/`): Blender, resize, dedup, the UVs, WebP, Meshopt and the comparison in one go, with a short summary; raw files and Blender's log in the version's `.export/` (not in git). Every script: [`tools/README.md`](../../app/prototypes/0.0.2/tools/README.md).
- **Saving the owner's `.blend` is allowed** (owner, 2026-10-13), but **say so first, every time**: the owner may have it open. Check Blender isn't running (PowerShell `Get-Process blender` shows the open file in `MainWindowTitle`, `*` = unsaved; its ~10 small child processes are its own), save a copy next to the file, then save; open it with its UI (`open_mainfile` without `load_ui=False`) or the owner's layout is lost. For bigger changes a script the owner runs is also fine.
- **The exports switch the collections as `export-collections.json` says** (a new one stays off and is flagged), show hidden objects and leave pose mode, in memory. **The ship export takes `ship-export-list.json`**: read its `NOTE:` lines (listed but missing, in the file but unlisted). Every export stops on a `SCALE:` line if her armature isn't at scale 1, 1.23 tall. **A box tagged `reach: "through"` must be convex** (the game takes its hull). Coordinates in plans before 2026-10-19 are 1.19's units (×1.4856).
