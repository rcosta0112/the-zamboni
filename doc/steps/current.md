## Known traps

- **gltf-transform's `prune` in an export step:** limit it (`propertyTypes`, `keepAttributes: true`): by default it drops the lights' nodes and the normals of unlit meshes (the see-through copies read them).
- **Before any export:** read *Before the next export* in [`asset-pipeline.md`](../architecture/asset-pipeline.md#before-the-next-export). **Exporting:** `npm run export:ship` / `export:crew` / `export:player` (in `app/`): Blender, resize, dedup, Meshopt and the comparison in one go, with a short summary; raw files and Blender's log in the version's `.export/` (not in git). Every script: [`tools/README.md`](../../app/prototypes/0.0.2/tools/README.md).
- **Saving the owner's `.blend` is allowed** (owner, 2026-10-13), but **say so first, every time**: the owner may have it open. Check Blender isn't running (`tasklist`), save a copy next to the file, then save; open it with its UI (`open_mainfile` without `load_ui=False`) or the owner's layout is lost. For bigger changes a script the owner runs is also fine.
- **The exports switch the collections as `export-collections.json` says** (a new one stays off and is flagged), show hidden objects and leave pose mode, in memory. **The ship export takes `ship-export-list.json`**: read its `NOTE:` lines (listed but missing, in the file but unlisted). Every export stops on a `SCALE:` line if her armature isn't at scale 1, 1.23 tall. **A box tagged `reach: "through"` must be convex** (the game takes its hull). Coordinates in plans before 2026-10-19 are 1.19's units (×1.4856).
- **Collision corners (item 55):** Rapier's controller stops her dead on a vertical convex edge instead of sliding round it, and **overlapping shapes count apart** (a wedge over a square corner still stops her): smooth a corner inside the one convex shape. A probe that teleports her can start her within the controller's 3 cm gap of a surface: then she can't move at all (not a snag). The normal nudge factor and a retried slide didn't help (tried, reverted).
- **Doors: the ship export puts them at rest** (`rest-poses.json`); a door moved on purpose needs `npm run rest-poses -- --accept "<name>"`. A duplicated object keeps its tags. **Her jetpack is found by the exact name `Jetpack`** (a copy becomes `Jetpack.001`). **`resources/` can't be read with the file tools**, nor named in a shell command. Blender scripts read it; a node script run from the project root reaches it through `process.cwd()`; scripts go in the scratchpad. **ffmpeg** and **Python 3.11** are on the PATH. **Blender 5.2** is at `C:/Program Files/Blender Foundation/Blender 5.2/blender.exe` (not on the PATH); two add-ons print tracebacks at start: harmless.
- **The ship is turned half a turn in the world**, at scale 1 since 1.21 (1.486 before): Blender (x, y, z) is `ship.object.localToWorld(x, z, -y)`; the other way, `worldToLocal`, then (x, -z, y).
- **In checks:** she turns in an arc when she sets off (face her first, or she misses a doorway); teleported into a closed door she's stuck; several spots 2.5 m into engineering and the cockpit are inside furniture. **Flying needs `settings.wearingJetpack`.** `npm run probe` drops `--shot`: run `node tools/probe-01.mjs` for screenshots.
- **Flipping the single-sided switch rebuilds the shaders:** frames stall for seconds. In checks, wait on a value, not on a time. **A frame's `dt` can be below zero** on the first frame: clamp it where a fade depends on it.
- **Screenshots from a script:** wait 2 s after moving her before capturing. **Keep a long check's whole output in a file** (`npm run smoke > .export/smoke.txt`), never piped through `tail`: a cut-off run has to be run again (3.5 min).
- **In the Bash tool:** quote a heredoc's delimiter (`<<'EOF'`). Python edits: open for writing with `newline="\n"` (the default writes CRLF on Windows).
- **Nothing that is deleted and rewritten whole goes in a folder Vite watches** (item 57): `.export/`, `dist/` are ignored in `vite.config.ts`; a new such folder must be added there.
- **A dev server may already be running on 5202** (the owner's): the smoke script uses it, and `npm run dev` then fails (port taken). **After `vite.config.ts` or a dependency changes it restarts by itself**; if the page is blank, restart it by hand. **Restarting it:** `taskkill //PID <pid> //F` (`Stop-Process` failed), then start it detached (PowerShell `Start-Process cmd.exe '/c','npm run dev > prototypes\0.0.2\.export\dev.txt 2>&1'` in `app/`, hidden): run from the Bash tool's background it dies when the task ends.
- **Don't edit `src/` while the smoke script runs:** Vite reloads the page and the run dies (`reading 'exceptionDetails'`).
- **Dev hooks** on `window` in dev builds: `__settings`, `__character`, `__physics`, `__ship()`, `__entity('<id>')`, `__director()` (`start('<id>')`, `current`), `__cutscene()` (`play('<id>')`, `skip()`, `time`), `__story()` (`get`, `set`, `run`), `__save` (`read`, `clear`), `__view`, `__scene`, `__world`, `__interaction()` (`target`, `aimBy`, `marked`), `__ladders()`, `__boxes()` (`count`), `__audio` (`started`, `playing()`), `__boombox()`, `__rack()` (`hers`), `__outfit(set?)`, `__clothes()`, `__exhaust` (`shown`), `__flames()`, `__exterior()` (`shown`, `panes`, `compiledIn`), `__treadmill()`, `__wind` (`level`), `__start()` (`ready`, `begun`, `share`, `shown`, `animatic`), `__THREE`.
